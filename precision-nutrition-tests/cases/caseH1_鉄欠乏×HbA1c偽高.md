# H1（架空・女性38歳／鉄欠乏によるHbA1c偽高）※ダミーデータ

## 入力データ（問診票＋血液）

**基本情報**: 38歳 女性・BMI 20.8
**主訴**: 健診でHbA1cが高めと言われた。糖質制限をすべきか知りたい。疲れやすく冷えもある。
**問診**: 月経量やや多め。肉が少なめの食事。服薬なし。

| マーカー | 値 | 単位 |
|---|---|---|
| HbA1c | 5.9 | % |
| 空腹時血糖 | 88 | mg/dL |
| フェリチン | 9 | ng/mL |
| 血清鉄 | 38 | µg/dL |
| TIBC | 410 | µg/dL |
| MCV | 82 | fL |
| MCH | 26 | pg |
| Hb | 11.8 | g/dL |
| CRP | 0.02 | mg/dL |

## 合格条件

必ず拾う所見:
- **鉄欠乏（B1）** を検出（フェリチン9・鉄低・TIBC高・MCV/MCH低め、CRP低で偽高でない）
- **HbA1c 5.9 は鉄欠乏による偽高の可能性**と明示する
- 空腹時血糖88が良好であることとの**乖離**に触れる
- **鉄を整えるとHbA1cが下がりうる**ため、まず鉄の評価・改善を優先すると示す

やってはいけない誤り:
- HbA1cを額面どおり受け取り「糖代謝の問題」と断定する
- **いきなり糖質制限を主提案にする** ← 最も避けたい誤り
- 鉄欠乏を見落とす／鉄が足りていると誤る

> 出典: HbA1c補正ルール(S019)の回帰確認用。
