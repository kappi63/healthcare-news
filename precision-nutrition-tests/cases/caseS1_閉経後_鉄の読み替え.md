# S1（架空・閉経後女性／ライフステージで鉄の読み方が変わる）※ダミーデータ

## 入力データ（問診票＋血液）

**基本**: 女性 58歳・BMI 23.1／クライアントID: CL-902
**主訴**: 疲れやすい。以前「貧血ぎみ」と言われたので鉄のサプリを飲むべきか知りたい。
**問診**: 3年前に閉経。服薬なし。サプリなし。

| マーカー | 値 | 単位 |
|---|---|---|
| フェリチン | 210 | ng/mL |
| 血清鉄 | 128 | µg/dL |
| Hb | 13.4 | g/dL |
| MCV | 92 | fL |
| CRP | 0.05 | mg/dL |
| 総コレステロール | 248 | mg/dL |
| LDL | 158 | mg/dL |
| HDL | 62 | mg/dL |
| ALP | 61 | U/L |
| 25-OHビタミンD | 19 | ng/mL |
| TSH | 2.8 | µIU/mL |

## 合格条件

必ず拾う所見:
- **閉経後であることを踏まえ、鉄の優先度を下げる**。フェリチン210は充足〜過剰側であり
  **鉄サプリは不要**と明確に伝える（主訴への直接回答）
- フェリチン高値をCRP 0.05（低値）と照合し、**炎症の偽高ではない**＝真に貯蔵鉄が多いと鑑別（B2）
- **骨代謝と脂質の優先度を上げる**：25-OHD 19（不足域）、総コレ248/LDL158
- 総コレステロール上昇を即「食べ過ぎ」と決めつけず、**閉経に伴うホルモン変化**の影響に触れる
- 疲れやすさの背景を鉄以外（ビタミンD・甲状腺・たんぱく質・睡眠）で検討する

やってはいけない誤り:
- **鉄のサプリを勧める** ← 最も避けたい誤り（閉経後＋高フェリチン）
- 月経のある女性と同じ基準でフェリチンを読む
- 高フェリチンを見て炎症と即断する（CRPは低い）
- ビタミンD不足の見落とし

> 出典: ライフステージ修飾(S023)・症状逆引き(S022)の回帰確認用。
