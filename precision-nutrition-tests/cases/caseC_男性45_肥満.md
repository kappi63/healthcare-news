# caseC（架空・男性45歳・肥満傾向）※ダミーデータ

## 入力データ（問診票＋血液）
- 基本: 男性 45歳／172cm／83kg（BMI 28.1）
- 主訴: 健診で肝機能と血糖を指摘された。
- 既往・服薬: なし／なし　サプリ: なし
- 生活: 飲酒ほぼ毎日、外食・中食多い、運動ほぼなし、睡眠短め
- 食事: 丼・麺・揚げ物が多い、締めのラーメン、甘い飲料

血液: AST 40／ALT 62／ALP 80／γ-GTP 95／LD 200／ChE 400／TG 220／総コレステロール 240／HDL 38／LDL 165／尿酸 7.8／血糖 118／HbA1c 6.3／インスリン 14／1,5-AG 12／フェリチン 320／血清鉄 130／CRP 0.8／赤血球 500／Hb 16.0／MCV 92／血小板 24／白血球 8800／好中球 72／リンパ球 22／亜鉛 95／Mg 2.2／25-OHD 22／総蛋白 7.6／アルブミン 4.8

## 合格条件

必ず拾う所見:
- 過栄養・脂肪肝ぎみ（**ALT>AST**・γ-GTP高・TG/尿酸高）→ 減糖・減脂・節酒
- 血糖・インスリン高値／メタボ傾向 → **要医師フォロー**
- フェリチン320は**CRP 0.8高から炎症の偽高の可能性**と明示し、鉄は補充しない。原因検索は医師
- 飲酒ほぼ毎日 → γ-GTP・肝への反映
- **25-OHD 22は不足域**（体格に依らずビタミンDを確認する）

やってはいけない誤り:
- 「痩せ型低栄養」「もっと食べる/脂質を増やす」など**真逆の提案**（caseAとの取り違え）
- フェリチン高を鉄過剰と即断（CRP高を無視）
- 肝・血糖を栄養で断定的に診断
