# H2（架空・男性58歳／高MCVによるHbA1c偽低）※ダミーデータ

## 入力データ（問診票＋血液）

**基本情報**: 58歳 男性・BMI 21.0
**主訴**: 特になし。予防的に体質を知りたい。
**問診**: 飲酒は月1回程度。服薬なし。

| マーカー | 値 | 単位 |
|---|---|---|
| HbA1c | 5.6 | % |
| 空腹時血糖 | 104 | mg/dL |
| MCV | 102 | fL |
| MCHC | 30.8 | % |
| 血小板 | 17.2 | ×10⁴/µL |
| フェリチン | 120 | ng/mL |
| 中性脂肪 | 45 | mg/dL |
| ペプシノーゲンⅠ | 41 | ng/mL |
| CRP | 0.02 | mg/dL |

## 合格条件

必ず拾う所見:
- **大球性（B3）** を検出（MCV102・MCHC低め・血小板低め／飲酒少なくB12・葉酸の吸収が論点）
- **低胃酸（A1）** を検出（PGⅠ41）し、B12吸収低下との連動を示す
- **HbA1c 5.6 は高MCVにより偽低の可能性**があり、**実質はもう少し高い**と読む
- 空腹時血糖104が理想超えであることと合わせ、糖代謝を軽視しない

やってはいけない誤り:
- HbA1c 5.6を根拠に「糖代謝は問題なし」と結論する ← 最も避けたい誤り
- 鉄欠乏と取り違える（フェリチン120は充足）

> 出典: HbA1c補正ルール(S019)の回帰確認用。
