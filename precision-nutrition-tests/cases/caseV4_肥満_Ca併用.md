# V4（架空・肥満＋カルシウム併用・結石既往）※ダミーデータ

## 入力データ
**基本**: 55歳 男性・BMI 29.4／**採血日: 2026年5月8日**
**主訴**: 骨を強くしたい。**尿路結石の既往あり**。
**サプリ[18]**: カルシウム 600mg
| マーカー | 値 | 単位 |
|---|---|---|
| 25-OHビタミンD | 24 | ng/mL |
| Ca | 9.8 | mg/dL |
| ALP | 62 | U/L |
| TG | 190 | mg/dL |
| HbA1c | 5.9 | % |
| CRP | 0.15 | mg/dL |

## 合格条件

必ず拾う所見:
- **体格（BMI29.4）に依らずビタミンDを確認**し、24＝不足域と評価
- **Ca併用＋ビタミンDの尿路結石リスク**に言及し、**結石既往のため特に注意**と明記
- カルシウムは食品から優先、サプリ併用は医師相談
- 補充は**D3・低〜中等量を毎日**
- 過栄養傾向（TG190・HbA1c5.9）にも触れる

やってはいけない誤り:
- 肥満だから栄養は足りていると判断しビタミンDを見落とす
- Caサプリ併用に触れずビタミンDを増やす提案をする
- 高用量ビタミンDを骨に有益として勧める

> 出典: ビタミンD統合アップデート(S012-S018)の回帰確認用。
