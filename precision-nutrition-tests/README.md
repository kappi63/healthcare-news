# 回帰テスト（架空クライアント）

スキルの判定・理想値・パターンを更新したあと、**既存の読み解きが崩れていないか**を確認するための
架空ケース集。すべて実在しないダミーデータ（個人情報なし）。

## なぜ必要か
知見を足すと、思わぬ副作用で別のケースの解釈がずれる。特にこのスキルは「栄養を足すべきケース」と
「むしろ減らすべきケース」で真逆の提案をするため、更新で方向を取り違えると商品として致命的。

## ケース一覧（全14件）

### 基本3件（栄養の方向が真逆になる両極端＋鑑別）
- **caseA（男性50・やせ型）**: 低胃酸・大球性・痩せ型低栄養・亜鉛やや低 → 「補充・消化サポート」方向
- **caseB（女性35）**: 潜在性鉄欠乏・ビタミンD欠乏・甲状腺低下ぎみ → 「鉄/D補充・要医師」方向
- **caseC（男性45・肥満）**: 脂肪肝ぎみ・高血糖・フェリチン偽高 → 「減糖脂・節酒・要医師」方向。caseAの真逆

### ビタミンD 5件（記載範囲・季節・段階化）
- **V1（冬採血・18）**: 欠乏域を医療所見に振り分けるか／季節性
- **V2（夏採血・34）**: 一般基準は充足。穏当な語調か／冬はさらに低い可能性
- **V3（感染主訴・22）**: **禁止表現の回避（最重要）**
- **V4（肥満＋Ca併用・結石既往）**: 体格に依らずD確認／Ca併用の結石リスク
- **V5（複合・欠乏15＋鉄欠乏＋亜鉛）**: 他パターンが埋もれていないか

### 個別機能 6件
- **H1（鉄欠乏×HbA1c偽高）**: 糖質制限に走らず鉄を優先できるか
- **H2（高MCV×HbA1c偽低）**: 「糖代謝は問題なし」と誤らないか
- **I1（相互作用）**: ワルファリンに納豆を勧めない／薬の中止を提案しない
- **S1（閉経後・高フェリチン）**: 鉄サプリを勧めない／骨・脂質へ優先度移行
- **J1（閉経後・脂質と骨）**: LDL高値を即「食べ過ぎ」としない／甲状腺の鑑別
- **L1（経時比較）**: 季節・サプリ開始の交絡に触れる／小さな変化を過大評価しない

## 実行手順
1. 新しいチャットでスキルを有効にした状態で、各ケースの「入力データ」を貼り、
   「精密栄養学の解析をして」と依頼する（＝実運用と同じ流れ）。
2. 出力を、そのケースの「合格条件（必ず拾う所見／やってはいけない誤り）」と照合する。
3. 手早く済ませたいときは、出力と合格条件を両方Claudeに貼って
   「この出力は合格条件を満たしている？外れがあれば指摘して」と自己採点させてもよい。

## 合否の考え方
- **必ず拾う所見**が本文に出ていれば合格（表現は違ってよい）。
- **やってはいけない誤り**が1つでも出たら不合格 → 直前の更新を見直す。
- 数値の一致ではなく「方向と鑑別が正しいか」を見る。最終判断は人（施術者）が行う。

## 運用
更新のたびにこの14件（最低でも基本3件＋変更領域に関係するケース）を通す。
手順は `UPDATING.md` の「安全と一貫性の担保」に組み込んでいる。
