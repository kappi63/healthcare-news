# 追加提案: エストロゲン単独HRTと認知症・アルツハイマーリスク低下  （2026-08-17 / 記者AI）

## 1. 関連性
スタンフォード大学の大規模研究（21,462人、Neurology誌 2026-08-12掲載）が、閉経後女性の
エストロゲン単独ホルモン療法（HRT）と認知症リスク39%・アルツハイマー脳病変（アミロイド・タウ）
35%低下の関連を報告。

スキルとの接点：
- `terms.json` の "hormone" カテゴリ（エストロゲンによる銅上昇は S033 で交絡として記録済み）
- `lifestage.md` の閉経後ライフステージ（S023：骨・鉄・脂質の需要変化）
- `patterns.md` C2（長期アウトカム）/ watchlist.md T1（NIH NPH・認知機能と栄養の関連）
- 関連栄養素の候補：フィトエストロゲン（大豆イソフラボン・リグナン）、オメガ-3、
  ビタミンD（認知保護との関連が研究中）

ただし本研究の介入は**製薬的なホルモン補充療法**であり、食事・栄養介入ではない。

## 4. 実行可能性
本研究の知見（HRT→認知症リスク低下）を栄養カウンセリング助言に落とすのは困難：
- 推奨できる具体的な食事・補充行動として落ちない（HRT は医師が処方する薬物療法）
- フィトエストロゲン（大豆イソフラボン、亜麻仁のリグナン）を通じた間接的な
  「エストロゲン様作用と認知機能」の文脈は存在するが、本研究はその証拠ではない
- 「エストロゲン活性を高める食事」の推奨は、既存ルール（薬の変更提案禁止・
  ビタミンDの感染予防を謳わない等）の趣旨に照らし、疾患管理との混同リスクが高い
- 判定：**カウンセリング助言に直接は落ちない → 「枠組み記録」にとどめる**

## 6. 安全・医療フラグ
- **医師案件フラグあり**: ホルモン補充療法の開始・変更・中止は医師の判断。
  スキル上でHRTを勧めたり「エストロゲンを増やすと認知症が予防できる」と表現してはならない。
- 乳がん・子宮体がんとHRTのリスク-ベネフィット権衡は医師管理領域。
- フィトエストロゲン（大豆食品等）自体は食品として過剰リスクは低いが、
  ホルモン感受性腫瘍既往者への大量摂取推奨は避ける。
- 既存禁止表現との整合: 「エストロゲンを食事で増やせば認知症が防げる」等の決定論的表現は禁止。
