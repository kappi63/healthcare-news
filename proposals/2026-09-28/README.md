## 精密栄養スキルへの提案サマリー

### 精密栄養関連候補の選定プロセス

**対象ニュース5件**を、スキルが扱うマーカー・パターン（血液マーカー、ビタミン/ミネラル、
糖代謝・脂質・鉄・甲状腺・腸内・遺伝子・エピジェネティクス等）との関連で評価した。

| 候補 | 関連性 | 判定 | 理由 |
|------|-------|------|------|
| CRISPR療法とLDL/TG削減 | 低 | 見送り | 遺伝子編集による医薬品的介入。LDLは精密栄養スキルで扱うが、CRISPR療法自体は「薬の変更・中止を提案しない」ルールに抵触。栄養指導への落とし込みなし。 |
| CAR-T細胞療法とRA寛解 | なし | 見送り | 細胞免疫療法による疾患治療。精密栄養スキルの対象マーカー・パターンと直接関係なし。 |
| COVID-19ワクチン2026-27承認 | なし | 見送り | 感染症予防ワクチン。精密栄養スキルの対象外。 |
| REM睡眠と83疾患リスク低下 | 低 | 見送り | 睡眠の質と慢性疾患リスクの大規模観察研究。時間栄養学（S031）との間接的関連はあるが、REM睡眠自体は血液マーカー・栄養素パターンとの直接対応がない。栄養指導への具体的落とし込みが困難。 |
| オメガ3＋アスピリンと歯周炎RCT | 中 | 保留 | Journal of Periodontology掲載のRCT（PMID 39950354）。オメガ3（EPA/DHA）は精密栄養スキル未登録の栄養素。ただし疾患治療文脈・アスピリン（薬剤）との複合介入のため、スキルへの直接反映は保留。将来的なオメガ3項目追加の参考文献として記録。 |
