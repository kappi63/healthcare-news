## 本日のヘルスケアニュース5選（概要）
1. 腸内細菌が野菜の硝酸塩・非ヘム鉄を心代謝保護物質（DNIC）に変換（Cell誌 / Karolinska）
2. 肥満の「分子的記憶」が免疫細胞に体重減少後も5〜10年持続する可能性
3. ケトジェニック食が肝脂肪を臨床試験で67%削減、地中海食・低脂肪食より代謝改善効果大
4. CAR T細胞療法が重症関節リウマチで劇的な疾患活動性低下を示す
5. 新クラスの非オピオイド鎮痛薬suzetrigineが末梢神経選択的ナトリウムチャネル遮断で臨床試験成功
