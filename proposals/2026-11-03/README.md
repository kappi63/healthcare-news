## 除外理由メモ

| # | ニュース | 除外理由 |
|---|--------|--------|
| 1 | 非侵襲的肝臓診断（LITMUS） | 診断精度の研究（生検 vs 非侵襲的検査）であり、栄養介入・カウンセリング助言に直結しない。肝マーカー（ALT/AST/GGT）は既存パターンに収録済み。 |
| 2 | エボラ出血熱の拡大 | 感染症・公衆衛生の話題。精密栄養学の血液マーカー・栄養素スコープ外。 |
| 3 | 電子インプラントによる血糖制御 | 医療デバイスによる介入。栄養ではなく医療機器の話題。グルコース代謝への栄養的アプローチとは範囲が異なる。 |
| 4 | パンデミック備えの欠陥 | 医療政策・感染症対策の話題。精密栄養スキルのスコープ外。 |
| 5 | CHOICE試験（聴力介入とMCI） | 補聴器等による聴力介入試験。栄養・血液マーカーに直接関連しない。 |
