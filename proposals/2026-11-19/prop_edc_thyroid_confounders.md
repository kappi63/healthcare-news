# 追加提案: 内分泌かく乱物質（EDC）の甲状腺・代謝マーカーへの影響を交絡チェックリストに追加  （2026-11-19 / 記者AI）

## 1. 関連性
UNEP-WHO合同報告書（2026年11月公表）が、内分泌かく乱物質（EDC）——ビスフェノール類・フタル酸エステル・ペルクロレート等——が**甲状腺ホルモン調節・代謝・生殖機能**に与える悪影響について、以前より強力なエビデンスを示した。

精密栄養スキルは TSH・FT3・FT4 を主要マーカーとして扱い、パターンD（低代謝疑い）でセレン・鉄・ヨウ素との関連を解説している。EDCは甲状腺ホルモン受容体に競合するほか、ペルクロレートはヨウ素の甲状腺取り込みを阻害することが示されている。現行の confounders.md にはEDCへの言及がないため、TSH/FT3 が境界域の場合の交絡要因として注記を追加することが望ましい。

触れるマーカー/パターン: TSH、FT3、FT4、甲状腺パターン（D）、腸内環境（EDC-腸内細菌叢相互作用）、代謝マーカー（空腹時血糖・TG・HDL）

## 2. 新規性（重複チェック結果）
- `terms.json`：TSH・FT3・FT4 エントリにセレン・ヨウ素との関連は記載あり。EDC・ビスフェノール・ペルクロレートへの言及は**なし（新規）**。
- `patterns.md`：甲状腺パターン記述に環境化学物質への言及は**なし（新規）**。
- `confounders.md`：EDCへの言及は**なし（新規）**。

**判定: 新規追加**

## 3. エビデンスの強さ
情報源: UNEP・WHO合同報告書（State of the Science of Endocrine Disrupting Chemicals）2026年更新版。複数の系統的レビュー・疫学研究・動物実験を総合した公的機関の評価。  
タグ: **中程度**  
一言評価: 甲状腺へのEDC影響はメカニズムレベルでは確立（ペルクロレートのヨウ素競合阻害は確立）、一般集団の生活習慣介入効果については観察データが蓄積段階。公的機関評価なので信頼度は高いが、栄養カウンセリングへの直接の変換は「推奨」ではなく「注意事項」どまり。

## 4. 実行可能性
カウンセリング助言として落とせる内容:
- 食品中のEDC暴露を減らす実践的アドバイス（プラスチック容器の加熱使用を避ける、缶詰より瓶/冷凍を選ぶ、農薬残留の少ない食品を選ぶ）は既存の食生活指導の延長として伝えられる。
- ヨウ素・セレンの適切な摂取維持が、一部のEDCによる甲状腺機能阻害を緩和しうるという補足注記は、既存のマーカー解説内に収まる。

ただし「EDCを除去すれば甲状腺が正常になる」という断定は証拠不十分であり、推奨しない。**交絡チェックとしての記録に留め、変更提案はカウンセラーの裁量に委ねる形とする。**

## 5. 反映先（差分案）

差分案（confounders.md への追記案）:
```
### EDC（内分泌かく乱物質）による甲状腺マーカー偽影響
- **対象マーカー**: TSH・FT3・FT4
- **メカニズム**: ペルクロレート等はヨウ素の甲状腺取り込みを競合阻害し、TSH上昇・FT3低下を引き起こしうる。ビスフェノール・フタル酸エステルは甲状腺ホルモン受容体に競合する可能性が示されている。
- **確認項目**: 缶詰・プラスチック容器の多用、農薬高暴露の食生活が疑われる場合はEDC暴露を考慮する。
- **対応**: ヨウ素・セレンの摂取量確認。暴露低減の食生活アドバイス（プラスチック加熱回避・有機食品優先等）。疾患疑いなら医師紹介。
- 【根拠】UNEP-WHO EDC報告書2026年版（S037）＝【中程度】
```

## 6. 安全・医療フラグ
- 甲状腺疾患（橋本病・バセドウ病等）が疑われる場合は必ず医師案件とする。
- EDC暴露低減アドバイスは栄養・生活習慣の範囲内で伝えられるが、特定食品の「毒性」を強調する表現は避ける（薬機法・景品表示法に配慮）。
- 「EDCが甲状腺がんを引き起こす」等の断言はしない（エビデンス不十分）。
