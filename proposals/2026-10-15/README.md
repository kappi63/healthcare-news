## No.2 SURMOUNT-5 / GLP-1薬比較 — 見送りの根拠

**関連性**: GLP-1受容体作動薬（チルゼパチド・セマグルチド）は血糖代謝・体重管理に直接関係し、
patterns.md の C2（痩せ型高血糖）・F1（食後スパイク）・F2（血糖変動大）パターン、
および interactions.md（薬剤×栄養相互作用）に関連しうる。

**見送り理由**:
1. SURMOUNT-5は薬剤間の効果比較RCTであり、栄養介入の効果を直接検証した研究ではない。
2. スキルのルール「薬の変更・中止を提案しない」の観点から、どちらの薬が優れているかの情報を
   スキルに組み込むことは範囲外。
3. GLP-1薬服用中の栄養サポート（急速な体重減少時の筋肉量保護のためのタンパク質最適化など）
   についての栄養介入エビデンスは本研究では提供されていない。
4. 2026年10月14日の分析と同様に、GLP-1薬関連の栄養介入については一次情報（NEJM・Lancetの
   臨床試験、ADA/ESCガイドライン等でのGLP-1薬服用時の栄養推奨）が確認できた時点で正式提案する。

**推奨**: 見送り — 薬剤比較結果として情報を記録に留める。栄養介入の直接エビデンス確認後に改めて提案。
