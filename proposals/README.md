# proposals — 日次ニュースからの追加提案

スケジュールタスクが毎日ここに `YYYY-MM-DD/` を作り、精密栄養スキルへの
**追加提案**を出力します。**このフォルダの内容は提案であり、まだスキルには反映されていません。**

## 見方
各提案には8項目の理由が付いています。
関連性／新規性（重複チェック）／エビデンスの強さ／実行可能性／反映先（差分案）／
安全・医療フラグ／出典1行／回帰テストの対象。

## 採用したくなったら
その提案ファイルの内容を claude.ai のチャットに貼り、「これをスキルに反映して」と依頼してください。
反映・検証・回帰テスト・再パッケージまで行われ、更新用の .skill が返ります。

## ルール
- 正本（`precision-nutrition-analysis/`）はこのタスクでは書き換えません。
- **理想値（optimal/reference）は日次ニュース由来では変更しません。**
- 医療情報は必ず人がレビューしてから反映します。
