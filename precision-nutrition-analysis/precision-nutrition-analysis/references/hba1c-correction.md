# HbA1c 補正ルール（偽高・偽低の判定）

HbA1c は「赤血球が糖にさらされた履歴」を見る指標のため、**赤血球の寿命・大きさ・産生速度が変わると
血糖の実態とずれる**。この補正を怠ると、糖代謝の評価を系統的に誤る。本スキルのクライアント層では
「高MCV＋血糖境界域」「女性の潜在性鉄欠乏＋HbA1c」が頻出するため、独立した確認ステップとして扱う。

## 原理（ひとことで）
赤血球が**長く生きる/古い**ほど糖と結合する時間が長く HbA1c は**高く**出る。
赤血球が**新しく入れ替わる**ほど HbA1c は**低く**出る。
→ 「HbA1cの値」ではなく「その赤血球がどれだけ糖にさらされたか」を見ている。

## 判定フロー（Step 2 で血糖を評価する前に必ず通す）
1. **MCV・Hb・網赤血球・フェリチン・鉄** を確認する。
2. 下の表に該当すれば、HbA1c を額面どおりに読まない。
3. 可能なら **空腹時血糖・1,5-AG・GA（グリコアルブミン）・リブレのGMI** と突き合わせる。
4. レポートには「HbA1c は◯◯の影響で実際よりやや低め/高めに出ている可能性」と**推察の語調**で記載する。

## 偽低（実際の血糖より HbA1c が低く出る）
| 状況 | 手がかり | 解釈 |
|---|---|---|
| ビタミンB12・葉酸欠乏の**治療中/改善中** | MCV高値＋網赤血球↑ | 赤血球が新生し HbA1c は低めに出る |
| 溶血・出血後、赤血球寿命短縮 | Hb低下＋網赤血球↑＋間接ビリルビン↑ | 履歴が短く低めに出る |
| 鉄剤・B12/葉酸の補充開始後 | 補充歴（問診[18]）＋網赤血球↑ | 造血が動き低めに出る |
| 妊娠中（後期） | 妊娠 | 赤血球代謝亢進で低めに出やすい |
| 慢性腎臓病・肝硬変・脾機能亢進 | eGFR低下等 | 医師案件。額面で判断しない |

**本スキルで最も多い形**: 高MCV（B3 大球性）＋血糖が理想超え。この場合 HbA1c は**実質もう少し高い**
可能性があり、「HbA1c 5.8% だが実質やや高め」と読む（福山様のケースがこれ）。

## 偽高（実際の血糖より HbA1c が高く出る）
| 状況 | 手がかり | 解釈 |
|---|---|---|
| **鉄欠乏（貧血に至る前も含む）** | フェリチン低・鉄低・UIBC/TIBC高・MCV/MCH低め | 赤血球が長生きし HbA1c は高めに出る。**鉄補充で下がることがある** |
| ビタミンB12・葉酸欠乏（未治療） | MCV高値＋網赤血球↓ | 赤血球寿命が延び高めに出うる |
| 脾摘後・再生不良性貧血 | 既往 | 医師案件 |
| アルコール多飲・高ビリルビン等 | 問診・血液 | 検査法により干渉 |

**本スキルで最も多い形**: 女性の潜在性鉄欠乏（B1）＋ HbA1c が理想超え。鉄を整えると HbA1c が
下がることがあるため、**いきなり「糖質制限」に走らせない**。まず鉄の評価を優先する。

## 注意（読み違えやすい組み合わせ）
- **鉄欠乏 と B12/葉酸欠乏が併存**すると偽高・偽低が相殺され、MCVも正常に見えることがある
  （小球性＋大球性＝見かけ正球性）。MCVだけで否定せず、フェリチン・B12・網赤血球を個別に見る。
- **異常ヘモグロビン症**では測定法により大きくずれる。極端な乖離（GMIとHbA1cが1%以上違う等）は
  測定法の確認を含めて医師へ。
- 補正は「読み方の調整」であって**再計算ではない**。具体的な数値に換算して断定しない。

## 他モジュールとの連動
- **C2（痩せ型高血糖・糖化）**: 評価前に本ルールを通す。
- **B1（潜在性鉄欠乏）/ B3（大球性・メチル化）**: 該当時は必ず HbA1c の解釈に注記。
- **リブレ（F1/F2）**: **GMI と HbA1c の乖離が最良の検証手段**。GMI＞HbA1c なら偽低、GMI＜HbA1c なら
  偽高を疑う。CGMがあれば実測で裏づけられる。
- **AGEs（糖化年齢）**: HbA1cが偽低でもAGEsが高ければ、糖化の実態を支持する傍証になる。

## 代替指標（HbA1cが信頼できないとき）
- **グリコアルブミン（GA）**: 赤血球の影響を受けず、約2週間の平均血糖を反映。貧血時に有用。
- **1,5-AG**: 食後高血糖の指標。
- **リブレ（CGM）**: 実測。最も確実。
- 【根拠】赤血球動態によるHbA1cの偽高・偽低＝〔確立〕／各指標の使い分け＝〔確立〕
