# 旬の食材モジュール

提案する食材を、**その時期に手に入りやすく・おいしく・安いもの**に置き換えることで、
実行可能性を高める。栄養素そのものの提案は変えず、**「どの食材で摂るか」を季節に合わせる**のが役割。

## エビデンスの位置づけ（先に明確にしておく）
- 「旬は栄養価が高い」は**部分的にしか裏づけがない**。よく引かれるのはほうれん草のビタミンCで、
  食品成分表では通年平均 35mg/100g に対し**冬採りは 60mg**（露地栽培で日照が長いことが理由とされる）。
- ただし重要な限界として、**季節による成分値の違いはビタミンC以外ほとんど分析されていない**。
  他の栄養素まで一般化できる根拠は乏しい。〔限定的〕
- したがって、**「旬だから栄養が何倍」と数値で煽らない**。旬を勧める主な理由は次の3点に置く。
  1. **おいしい**（味がのり、続けやすい）
  2. **手に入りやすく安い**（実行のハードルが下がる）
  3. **食材の多様性が自然に増える**（季節ごとに変わるため。多様性は腸内環境G1にも寄与）
- 【根拠】ビタミンCの季節差＝〔一部確立（成分表）〕／他の栄養素への一般化＝〔限定的〕／
  多様性・実行可能性の利点＝〔妥当な運用〕

## 使い方
1. 血液・問診から**必要な栄養素**を先に決める（ここは季節に関係なく決まる）。
2. その栄養素を含む食材のうち、**今の時期に旬のもの**を優先して提案に書く。
3. 旬でない時期は、**冷凍・缶詰・乾物でも構わない**と添える（実行可能性を落とさない）。
   例: 冷凍野菜・サバ缶・乾燥わかめは通年で使え、栄養面でも実用的。

## 季節の目安（日本・一般的な時期。地域差あり）

### 春（3〜5月）
- **魚介**: 鰆、鯛、あさり、しらす、ホタルイカ
- **野菜**: 菜の花、春キャベツ、新玉ねぎ、アスパラガス、たけのこ、そら豆、新じゃが
- **相性のよい栄養テーマ**: 葉酸（菜の花・アスパラ）、鉄（あさり）、食物繊維

### 夏（6〜8月）
- **魚介**: 鰺、鰹（初鰹）、鱧、うなぎ、枝豆（豆）
- **野菜**: トマト、きゅうり、なす、ピーマン、オクラ、ゴーヤ、とうもろこし、モロヘイヤ
- **相性のよい栄養テーマ**: 水分・カリウム（発汗）、ビタミンB群（鰹・うなぎ）、
  抗酸化（トマト・ピーマン）
- **注意**: 食欲低下で**たんぱく質が不足しやすい**季節。冷たい麺に偏る人は要確認。

### 秋（9〜11月）
- **魚介**: 秋刀魚、鮭、鯖、戻り鰹、牡蠣（後半）
- **野菜・きのこ**: さつまいも、かぼちゃ、里芋、きのこ類（しめじ・まいたけ・しいたけ）、栗、銀杏
- **相性のよい栄養テーマ**: オメガ3（秋刀魚・鯖）、ビタミンD（きのこ・鮭）、食物繊維・
  レジスタントスターチ（芋類）
- **注意**: 糖質が増えやすい季節。血糖テーマ（C2/F1）の人は量と食べ方に触れる。

### 冬（12〜2月）
- **魚介**: ぶり、たら、牡蠣、ほたて、金目鯛
- **野菜**: ほうれん草、小松菜、白菜、大根、ねぎ、ブロッコリー、春菊、かぶ
- **相性のよい栄養テーマ**: 亜鉛（牡蠣）、鉄・葉酸（ほうれん草・小松菜）、
  ビタミンC（冬採りの葉物）、たんぱく質（ぶり・たら）
- **注意**: ビタミンD が最も下がる季節（`vitamin-d-evidence.md` の季節補正と連動）。

## レポートへの反映
- 改善プランの食材例を、**その時期の旬に置き換えて書く**だけでよい。旬であることを強調しすぎない。
  例:「たんぱく質は、今の時期なら**ぶり**や**たら**が手に入りやすく、鍋にすると続けやすいと思います」
- 「旬だから栄養価が高い」と数値で煽らない。おいしさ・手に入りやすさ・続けやすさを理由にする。
- 旬でない時期の代替（冷凍・缶詰・乾物）も添え、実行を妨げない。
- 採血日・問診日ではなく、**レポート作成時点の季節**で判断する。地域差にも留意する。
