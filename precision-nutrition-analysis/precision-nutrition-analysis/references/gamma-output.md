# Gamma出力モード（プレゼンテキストの作り方）

解析結果を、Gammaが取り込みやすい**プレゼン用Markdown**として出力するモード。
商品体裁（クライアント向けスライド）は、このテキストをGammaに貼ってAIでデザインする前提。

## Gamma取り込みの原則（この形に合わせる）
- Gammaはテキストを取り込み、**見出しごとに1カード（スライド）**へ分割する。→ カードにしたい単位を
  `##` 見出しで区切る。
- 太字・箇条書き・引用（`>`）などのMarkdownに対応。装飾・レイアウトは取り込み後にGamma側で付与する
  （テキストのみ取り込み）。
- 受け渡し: 出力したMarkdownを Gamma の「Create new AI → Import / Paste」に貼る。必要なら `/split` で
  カードを微調整。ブランド配色（スレート/ブルー/マスタードゴールド）はGammaのテーマで再現する。

## 書き方ルール（重要）
- **1カード＝1メッセージ**。詰め込まない。
- 箇条書きは各1行・短く（目安20〜30字）。長い段落を作らない（読みやすく割れない）。
- 重要な数値は**太字**。専門語はやさしい言葉に開く。
- 詳細レポート（Word）との違い: プレゼンは**結論と行動に絞る**。分子レベルの詳しい解説はWordに残し、
  スライドは「何が・なぜ大事か・どうする」を簡潔に。
- グラフ/画像はGamma側で追加する前提。必要な箇所に `> [挿入: 時間帯別血糖グラフ]` のような
  プレースホルダーのメモを残す。

## 標準カード構成（クライアント向け）
`##` 見出し＝1カード。ケースに応じて増減する。

```
# {{CLIENT_NAME}}様 精密栄養レポート
〈テーマ／日付〉

## 今日のまとめ
> 〈体内で起きていることの一言サマリー〉
- ポイント1（短く）
- ポイント2
- ポイント3

## あなたの良いところ（維持したい強み）
- 〈良好な項目を2〜4個、短く〉

## 気になるサイン
- **〈マーカー 数値〉**：〈意味を1行で〉
- **〈マーカー 数値〉**：〈意味を1行で〉
（2〜4個まで。詰め込みすぎない）

## 血糖の動き（リブレがある場合）
> [挿入: 時間帯別血糖グラフ]
- 平均・変動などの要点を1〜3行
- スパイク/低血糖のポイント

## 腸内環境（腸内フローラがある場合）
- 多様性・有用菌・酪酸産生菌の要点を1〜3行

## 今回の課題（2〜3つ）
- 課題1
- 課題2
- 課題3

## 食事プラン
- 〈具体策を5点以内、各1行〉

## 生活プラン
- 〈2〜3点、各1行〉

## 解決へのロードマップ
- Step 1　〈短く〉
- Step 2　〈短く〉
- Step 3　〈短く〉

## 今日からできる一歩
- 〈1〜2個だけ。最初の行動〉

## ご注意
- 本資料は栄養カウンセリングの参考情報で、医学的診断ではありません。
- 治療中・気になる症状は主治医にご相談ください。
```

## 出力時の注意
- 免責カード（ご注意）は**必ず入れる**。プレゼンでも「診断ではない／主治医相談」を省かない。
- 推察の語調（「〜が示唆されます」）と、機能性検査の仮説段階の扱いは、簡潔にしても保つ。
- 依頼に応じて、Word詳細レポートと Gamma用テキストの**両方**を出力してよい（内容は整合させる）。
