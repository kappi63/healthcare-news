# 問診票スキーマ（設問 → 解釈 → 関連マーカー／栄養素 → レポートへの活かし方）

実運用の問診票（44項目）に基づく確定版。出力はGoogle/Airtableのグリッド → CSV（1行＝1クライアント）。
**血液検査PDFは項目[27]に同梱される**ため、問診票CSVがクライアントのマスター記録になる。

> **識別子の取り扱い**: CSVには氏名・連絡先等が含まれる。読み込み時に `references/privacy-handling.md` の
> Step 0 に従ってマスクする。解析に必要なのは**年齢・性別・体格**のみで、氏名や生年月日そのものは不要。

## 派生値（まず計算する）
- **年齢** = 回答日[0] − 生年月日[1]。理想値の年齢補正・GFR解釈に使用。
  **年齢を算出したら生年月日は破棄し、以後は年齢（歳）のみを使う**（作業ファイルにも残さない）。
- **BMI** = 体重[3] ÷ (身長[2]/100)²。やせ/肥満傾向、増量/減量の方向づけ。

| [13]喫煙 | 選択 | CRP, WBC | 酸化ストレス。ビタミンC |

> **⚠️ [13]喫煙・[14]飲酒は「提案の材料」であると同時に「判定の交絡因子」でもある。**
> 飲酒は MCV・γ-GTP・TG・尿酸・HDL・フェリチンを、喫煙は Hb/Ht・WBC・CRP を
> 栄養と無関係に動かす。**特に「飲酒→MCV↑をB12欠乏と誤読」「喫煙→Hb↑で鉄欠乏がマスク」の
> 2つは頻出**。判定に入る前に `references/confounders.md` を通すこと。

### C. 服薬・サプリ（[15]-[18]）※禁忌・交絡チェック
| 設問 | 形式 | 使い方 |
|---|---|---|
| [15]薬の有無 [16]薬名 | 有無/自由 | 禁忌・薬剤性の交絡を確認。該当提案に主治医相談を明記 |
| [17]サプリ有無 [18]サプリ名 | 有無/自由 | 既補給を把握。数値と照合し重複・過剰を避ける |

- **薬剤の交絡例**: 胃酸抑制薬（PPI・H2ブロッカー）→ 胃酸低下でPGⅠ低値やB12・鉄・亜鉛の吸収低下を薬剤性として解釈／スタチン → CK・筋への影響／抗凝固薬（ワルファリン）→ ビタミンK・納豆など食材提案に注意。
- **サプリ照合例**: ビタミンD/オメガ3を既摂取 → 25-OHD・TGの数値と突き合わせ、効果と過不足を評価。鉄剤 → フェリチンと照合。

## 重要フラグ（自由記述[4][5][25]から必ず拾う）
以下は血液所見の解釈を大きく変える／安全上重要なため、見つけたら明示的に扱う。
- **胃全摘・胃切除** → 内因子欠如でビタミンB12が経口吸収されない。大球性（MCV高値）は必発しうる。B12補充は舌下/非経口や医師管理を前提に記述。
- **消化器症状（下痢・胸焼け・逆流・胃もたれ）** → 消化吸収のボトルネック。PGⅠ・TP・鉄/B12と結び付ける。
- **アレルギー・不耐（鶏卵・小麦・乳等）** → 該当食材を提案から除外。
- **家族歴（がん・生活習慣病等）** → 医療領域として踏み込まず、必要に応じ主治医/受診勧奨に留める。
- **服薬（[16]）** → 上記Cの交絡・禁忌に反映。

## クロス分析の型（Step 2で使用）
問診票の自覚症状/生活と血液所見を双方向に突き合わせる。
- 「疲れやすい・冷え」＋フェリチン低め → 鉄
- 「胃もたれ・肉が苦手・少食」＋PGⅠ低＋TP低 → 胃酸/消化力
- 「甘い物が多い・運動少」＋HbA1c高め → 血糖
- 「毎日飲酒」＋γ-GTP/MCV高め → アルコール・B群
- 「胃全摘」＋MCV高値 → B12（原因が明確化）

**逆向きの読み（交絡）も同時に行う。** 上は「問診が血液所見を説明する」向き。
下は「問診が血液所見を打ち消す」向きで、こちらを忘れると誤った提案になる。
- 「週2〜3回以上の飲酒」＋MCV高値 → **B12欠乏と断定しない**（アルコールとの鑑別）
- 「喫煙」＋Hb正常 → **鉄充足と読まない**（フェリチンを必ず確認）
- 「採血前に運動」＋AST/CK高値 → **肝障害と読まない**
- 「CRP上昇」＋亜鉛低値/フェリチン高値 → **栄養欠乏・鉄充足と読まない**（急性期反応）
- 「食後採血」＋TG高値 → **脂質異常と断定しない**
詳細は `references/confounders.md`。
