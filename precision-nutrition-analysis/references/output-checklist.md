# 出力前セルフチェックリスト（毎回の品質ゲート）

レポート／プレゼンテキストを出力する**直前**に、この項目を自己点検する。
回帰テストが「更新時」の品質保証なら、これは「毎回の出力」の品質保証にあたる。
1つでも該当したら、出力前に直す。

## 0. 最小ゲート（時間がないときでもこの6つだけは必ず）

このリストは長い。**すべてを毎回丁寧に通せないときでも、以下6つは飛ばさない。**
過去に実際の不具合が出たのは、いずれもこの6つのいずれかである。

- [ ] `python3 scripts/check_deidentification.py` → 終了コード0
- [ ] `python3 scripts/check_expressions.py` → ［要修正］0件
- [ ] eGFR 60未満なら、たんぱく質の増量提案を**していない**
- [ ] 薬の変更・中止を**提案していない**
- [ ] 充足している栄養素にサプリを勧めて**いない**
- [ ] PDF化して目視した（レイアウト崩れは機械チェックでは出ない）

## 1. 安全・免責（最優先）
- [ ] 「本レポートの前提条件」と「解析結果に関する注意事項」が**両方**入っているか
- [ ] 診断的な断定（「〜という病気です」「〜症です」）を使っていないか。推察の語調か
- [ ] 医師案件（下記）に該当する所見に、主治医相談を明記したか
      → 重度・進行性の異常値、貧血の出血源、甲状腺、疾患関連の遺伝型（HFE/APOE ε4）、
        頻回・重度の低血糖、著明な高血糖、器質的疾患を疑う症状（血便・体重減少等）
- [ ] **薬の変更・中止**を提案していないか
- [ ] 相互作用チェック（`interactions.md`）を通したか。該当箇所に相談の一文を添えたか
- [ ] **サプリ提案の4条件**（`supplement-criteria.md`）を通したか。充足している栄養素を勧めていないか
- [ ] サプリを提案した場合、**目標・確認時期・体感の指標**をセットで書いたか
- [ ] 既にサプリを摂っている場合、足す前に現在の内容を評価したか（重複・過剰・不要の整理）
- [ ] 妊娠・授乳・小児に、用量を伴う提案をしていないか

## 1-B. 表現の規制（薬機法・医療広告）— `expression-guard.md`
- [ ] **効果を断定していないか** → 治る／効きます／効果があります／〜が改善します／予防できます
- [ ] **例外なしを含意していないか** → 絶対に／確実に／誰でも／100%／副作用はありません
      （「**必ず**主治医にご相談ください」は定型文なので可）
- [ ] 主語が「体」でなく「栄養素」になっているか（体を主語にすると効能表現になる）
- [ ] 効果・変化に触れた章に、**個人差の一文**を1回置いたか
- [ ] その一文が、前提条件・注意事項の定型文と**重複していないか**（不安を煽らない）
- [ ] 「病気が治った」と読める体験談の書き方をしていないか
- [ ] 資格名を列挙していないか／他院・他社と優劣を比較していないか
- [ ] 定義の曖昧な効能句を使っていないか → 免疫力アップ／代謝が上がる／デトックス／毒素を出す
- [ ] **`scripts/check_expressions.py` を実行し、［要修正］0件を確認したか**

## 2. データの正確性
- [ ] 転記した数値が原本（PDF等）と一致しているか。単位は正しいか
- [ ] 性別・年齢に対応した理想値で判定しているか
- [ ] **HbA1c** を額面どおり読んでいないか（`hba1c-correction.md`：高MCV→偽低／鉄欠乏→偽高）
- [ ] **フェリチン高値**を、CRPと照合して「炎症の偽高」と鑑別したか
- [ ] **25-OHD** の採血月（季節）に触れたか。理想値と一般基準を混同していないか
- [ ] 判別しにくい値を推測で書いていないか（不確かなら本文から外す）
- [ ] **交絡因子チェック（`confounders.md`）を通したか**
      - [ ] 飲酒あり → MCV高値をB12欠乏と断定していないか／HDL高値を「良好」と称えていないか
      - [ ] 喫煙あり → Hb正常で鉄充足と読んでいないか（フェリチンを確認したか）
      - [ ] CRP上昇 → 亜鉛低値を欠乏、フェリチン高値を鉄充足と読んでいないか
      - [ ] 絶食・採血時刻が不明 → TG・血糖・コルチゾール・血清鉄を断定していないか
      - [ ] 高用量ビオチン摂取 → 甲状腺の値をそのまま判定していないか
- [ ] 交絡に該当した所見に、**次回そろえる条件**を書いたか

## 3. 記載範囲・エビデンス
- [ ] 禁止表現を使っていないか
      → 「ビタミンDは感染を予防する」「サブグループでは有効性が確認されている」
        「やせ菌／デブ菌」「この遺伝子があるから〇〇病」
        「サプリで生物学的年齢が若返る」「生物学的年齢が○歳若い」（時計により結論が異なる）
- [ ] **解析対象外の検査**（カンジダ／オリゴスキャン等）を所見の根拠にしていないか。
      受け取った旨は書いたか（黙殺していないか）。除去食・キレーション・抗真菌サプリを勧めていないか
- [ ] ビタミンDの食材で、**きのこ（D2）と魚（D3）を同列に並べて**いないか
- [ ] 〔確立〕と〔精密栄養／仮説〕を書き分けたか（後者は「〜とする考え方があります」）
- [ ] 腸内細菌・エピジェネティクスの個別効果を断定していないか
- [ ] 遺伝子を「体質・確率であり、生活で変えられる」という枠組みで扱ったか

## 4. 理想値の不変
- [ ] **理想値（optimal/reference）を勝手に変更・独自解釈していないか**
- [ ] 「理想値未達」と「一般基準で異常」を混同していないか（不安を過度に煽らない）

## 5. 構成・体裁
- [ ] `report-template.md` のアジェンダ順になっているか
- [ ] 経時比較がある場合、「前回からの変化」を入れ、交絡（季節・サプリ開始・採取条件）に触れたか
- [ ] **継続回（2回目以降）は継続回のアジェンダを使ったか**（初回と同じ全マーカー解説を繰り返していないか）
- [ ] 継続回で、提案を「続ける／変える／やめる（卒業）」に分類したか。**達成した項目を黙って残していないか**
- [ ] 継続回の「次回までの一手」が**ひとつだけ**になっているか
- [ ] 前回お願いした一手ができたかに触れたか（できていない場合、同じ形で再提示していないか）
- [ ] クライアントIDを識別欄とファイル名に入れたか。氏名がない場合に氏名を創作していないか
- [ ] 良好な項目を具体的に称えたか（課題の指摘だけになっていないか）
- [ ] 提案が実行可能か（食材・量・タイミングまで落ちているか）。数を絞ったか
- [ ] 主訴・目標に答えているか（データ主導だけになっていないか）
- [ ] **Word出力をPDF化して目視したか**（`docx-layout.md`）。行間が均一か・表がはみ出していないか・ページ末で不自然に切れていないか
- [ ] 全段落に `snapToGrid: false` が効いているか（`scripts/fix_grid.py --check` で確認できる）
