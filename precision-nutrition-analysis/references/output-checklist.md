# 出力前セルフチェックリスト（毎回の品質ゲート）

レポート／プレゼンテキストを出力する**直前**に、この項目を自己点検する。
回帰テストが「更新時」の品質保証なら、これは「毎回の出力」の品質保証にあたる。
1つでも該当したら、出力前に直す。

## 1. 安全・免責（最優先）
- [ ] 「本レポートの前提条件」と「解析結果に関する注意事項」が**両方**入っているか
- [ ] 診断的な断定（「〜という病気です」「〜症です」）を使っていないか。推察の語調か
- [ ] 医師案件（下記）に該当する所見に、主治医相談を明記したか
      → 重度・進行性の異常値、貧血の出血源、甲状腺、疾患関連の遺伝型（HFE/APOE ε4）、
        頻回・重度の低血糖、著明な高血糖、器質的疾患を疑う症状（血便・体重減少等）
- [ ] **薬の変更・中止**を提案していないか
- [ ] 相互作用チェック（`interactions.md`）を通したか。該当箇所に相談の一文を添えたか
- [ ] 妊娠・授乳・小児に、用量を伴う提案をしていないか

## 2. データの正確性
- [ ] 転記した数値が原本（PDF等）と一致しているか。単位は正しいか
- [ ] 性別・年齢に対応した理想値で判定しているか
- [ ] **HbA1c** を額面どおり読んでいないか（`hba1c-correction.md`：高MCV→偽低／鉄欠乏→偽高）
- [ ] **フェリチン高値**を、CRPと照合して「炎症の偽高」と鑑別したか
- [ ] **25-OHD** の採血月（季節）に触れたか。理想値と一般基準を混同していないか
- [ ] 判別しにくい値を推測で書いていないか（不確かなら本文から外す）

## 3. 記載範囲・エビデンス
- [ ] 禁止表現を使っていないか
      → 「ビタミンDは感染を予防する」「サブグループでは有効性が確認されている」
        「やせ菌／デブ菌」「この遺伝子があるから〇〇病」
- [ ] 〔確立〕と〔精密栄養／仮説〕を書き分けたか（後者は「〜とする考え方があります」）
- [ ] 腸内細菌・エピジェネティクスの個別効果を断定していないか
- [ ] 遺伝子を「体質・確率であり、生活で変えられる」という枠組みで扱ったか

## 4. 理想値の不変
- [ ] **理想値（optimal/reference）を勝手に変更・独自解釈していないか**
- [ ] 「理想値未達」と「一般基準で異常」を混同していないか（不安を過度に煽らない）

## 5. 構成・体裁
- [ ] `report-template.md` のアジェンダ順になっているか
- [ ] 経時比較がある場合、「前回からの変化」を入れ、交絡（季節・サプリ開始・採取条件）に触れたか
- [ ] クライアントIDを識別欄とファイル名に入れたか。氏名がない場合に氏名を創作していないか
- [ ] 良好な項目を具体的に称えたか（課題の指摘だけになっていないか）
- [ ] 提案が実行可能か（食材・量・タイミングまで落ちているか）。数を絞ったか
- [ ] 主訴・目標に答えているか（データ主導だけになっていないか）

## 6. 文体
- [ ] 数値の羅列でなく「なぜそうなるのか」を説明したか
- [ ] 推察の語調（「〜が示唆されます」）を保っているか
- [ ] 不安を煽らず、前向きで実行しやすいトーンか

---

**運用**: Step 6（安全チェック）でこのリストを通す。Gamma出力時も、簡潔にしても
1（安全・免責）と3（記載範囲）は必ず保つ。
