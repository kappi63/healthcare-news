# 食事応答の個人差（PPGR）モジュール

「同じ食事でも、血糖の上がり方は人によって大きく違う」という精密栄養学の核心を扱う。
リブレ（F1/F2）と腸内フローラ（G1-G3）を**理論的につなぐ**層であり、両モジュールの価値を高める。

## 中心となる知見
- **食後血糖応答（PPGR: postprandial glycemic response）には大きな個人差がある**。
  同一の食品でも、人によって上がり方・戻り方がまったく違う。食品の「GI値」は集団平均であり、
  個人の反応を必ずしも予測しない。
- 血液指標・食事内容・体格・身体活動・**腸内細菌叢**を統合すると、その人のPPGRをある程度
  予測できることが示されている。予測に基づく個別化食事介入が、盲検ランダム化試験で
  **食後血糖を有意に低下させ、腸内細菌叢にも一貫した変化**をもたらした。〔確立寄り〕
- **反応者／非反応者（responder / non-responder）という視点**: 同じ介入でも効く人と効かない人がいる。
  例として、食物繊維で糖代謝が改善した人は *Prevotella copri* が多く、複合多糖の発酵能が高かった
  という報告がある。腸内細菌が「食事応答を分ける要因のひとつ」になりうる。〔研究蓄積〕

## 実務への落とし込み（このモジュールの使いどころ）
1. **一般論より実測を優先する**
   リブレがあるなら、「この食品は血糖を上げにくいとされる」より**「あなたの場合はこう動いた」**を
   根拠にする。GI値や一般的な推奨は出発点にすぎない、という姿勢で書く。
2. **同じ食品でも人によって違う、と明示する**
   クライアントが「玄米が良いと聞いたのに上がる」と感じたときに、それは矛盾ではなく個人差だと
   説明できる。自己観察を否定せず裏づける（福山様の「冷やご飯は上がりにくい」等）。
3. **効かないときは「反応者でない可能性」を先に検討する**
   提案が効かなかった場合、努力不足や自己管理の問題にせず、**個人差・腸内環境・実行条件**を
   先に見直す。責めない姿勢の科学的な根拠になる。
4. **腸内環境の改善は「食事応答そのものを変えうる」と位置づける**
   酪酸産生菌（G2）や食物繊維の多様性は、単に腸の話ではなく**血糖の応答性に関わる**。
   リブレの改善と腸内環境の改善を、ひとつのストーリーとして語れる。
5. **検証のループを回す**
   提案 → リブレで実測 → 効いた/効かなかったを確認 → 次の提案を調整。経時比較
   （`longitudinal-comparison.md`）と組み合わせると、その人専用の食事法に近づいていく。

## 統合の視点
- **リブレ（F1/F2）× 食事記録**: どの食事でスパイクしたかを特定できれば、それがその人のPPGRの実測値。
- **腸内フローラ（G2 酪酸産生菌・多様性）× 血糖**: 食物繊維・レジスタントスターチへの反応の差を説明。
  玄米・冷やご飯は酪酸産生菌のエサであり、血糖と腸内環境の**両方**に効く接点。
- **遺伝（H2 TCF7L2/FTO）× 血糖**: 遺伝は傾向、リブレは実測。両者を「地図と現在地」として使う。
- **AGEs（糖化年齢）**: 食後スパイクの積み重ねの結果として読める。

## 書き方の注意
- 「あなたのPPGRを予測しました」とは書かない。**予測モデルを持っているわけではない**。
  あくまで「個人差が大きいので、実測（リブレ）と自己観察を重視します」という姿勢に留める。
- 特定の菌（P. copri 等）の有無で食事法を断定しない〔研究段階〕。
- 一般的な推奨（GI値・食べ順）を否定するのではなく、**出発点として使い、実測で調整する**と位置づける。
- 【根拠】PPGRの個人差と予測モデルの有効性＝〔確立寄り〕／個別の菌と反応者性＝〔研究蓄積〜仮説〕

## レポートへの反映
- リブレがある場合、「血糖の動き」の小節で「同じ食品でも反応は人により異なるため、
  ご自身の実測が最も確かな手がかりです」という趣旨を自然に織り込む。
- 提案の効果を検証する前提で書く（「次回のデータで一緒に確認しましょう」）。
