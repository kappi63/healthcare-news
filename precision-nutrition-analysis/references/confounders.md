# 交絡因子チェック（判定の前に通す）

血液の値は「その人の栄養状態」だけを映していない。**生活習慣・採血条件・生理的状態が、
栄養と無関係に値を動かす**。これを見落とすと、栄養欠乏でないものを欠乏と読み、
逆に本当の欠乏を見かけの正常値に隠される。

HbA1c だけは影響が大きく頻出するため独立ファイル（`hba1c-correction.md`）にしてある。
本ファイルは**それ以外のすべてのマーカー**を対象にした横断チェック。

## 使い方（Step 2 の冒頭）

1. 問診票の [8]〜[14]（睡眠・排便・喫煙・飲酒）、[15]〜[18]（服薬・サプリ）、[25] 特記事項を確認する。
2. 採血の**日付・時刻・絶食の有無**を確認する。記載がなければ「不明」として扱い、断定を弱める。
3. 下の表で該当するものを拾い、**その因子が動かしうるマーカーの解釈を保留または調整**する。
4. 保留したものはレポートに「〜の影響を受けている可能性があるため、次回は条件をそろえて確認しましょう」と書く。

> **原則：交絡が疑われるときは、栄養欠乏と断定しない。** 消すのではなく、断定の強さを下げる。

## 1. 生活習慣

### 飲酒 ［問診 14］
| 動くマーカー | 方向 | 誤読しやすい点 |
|---|---|---|
| γ-GTP | ↑ | 肝そのものの障害と混同しない。節酒2〜4週で戻ることが多い |
| AST・ALT | ↑（**AST > ALT** になりやすい） | 脂肪肝は逆に ALT > AST が多い。比率で分ける |
| **MCV** | ↑ | **B12・葉酸欠乏と紛らわしい最重要ポイント**。B3（大球性）を立てる前に飲酒量を確認する |
| TG | ↑ | 脂質異常と断定しない |
| 尿酸 | ↑ | ビール以外でも上がる |
| **HDL-C** | ↑ | **「HDLが高くて良好です」と称えない**。飲酒由来のHDL上昇は保護的とは限らない |
| フェリチン | ↑ | 鉄充足と誤読しない（`terms.json` ferritin の high も参照） |

→ 飲酒が「週2〜3回」以上なら、上記の解釈に必ず一言添える。ALDH2 の遺伝型があれば H3 と連動。

### 喫煙 ［問診 13］
| 動くマーカー | 方向 | 誤読しやすい点 |
|---|---|---|
| **Hb・Ht・RBC** | ↑ | 一酸化炭素への代償で赤血球が増える。**鉄欠乏が見かけ上マスクされる**。Hb正常でもフェリチンを必ず見る |
| WBC・好中球 | ↑ | 感染・炎症と即断しない |
| CRP | 軽度↑ | 同上 |
| HDL-C | ↓ | — |
| ビタミンC | 消費↑ | 需要が高まる（提案の根拠になる） |

### 直近の激しい運動（採血前 2〜3日）
- **CK が大きく上がる**（数倍〜）。AST・LD・尿酸・カリウムも上昇。
- → **筋由来を肝障害と読み違えない**。AST↑でALT正常、CK↑↑なら筋由来を先に疑う。
- 問診に運動習慣があっても「採血直前の運動」は別問題。記載がなければ確認候補にする。

### 睡眠不足・強いストレス
- コルチゾール・血糖・血圧が上がりうる。単回の値で HPA 軸（E2）を断定しない。

## 2. 採血の条件

### 絶食していない／食後採血
| マーカー | 影響 |
|---|---|
| **TG** | 食後は大きく上昇（食事内容で数倍）。**非空腹時TGを脂質異常と断定しない** |
| 血糖・インスリン | 上昇 |
| 鉄（血清鉄） | 食事・鉄剤で上昇 |

→ 絶食の有無が不明な TG 高値は、「条件を確認したうえで再評価」に回す。

### 採血時刻（日内変動）
| マーカー | 変動 |
|---|---|
| **コルチゾール** | 朝が高く夕方に下がる。**採血時刻なしに評価しない** |
| **血清鉄** | 朝高く夕方低い。変動が大きく、フェリチン・TSAT で補う |
| TSH | 夜間〜早朝に高い。境界域は時刻を添えて解釈 |

### 脱水・駆血が長い・溶血
- **脱水**：TP・Alb・Hb・Ht・BUN が**そろって見かけ上高く**なる。TP高値を「たんぱく質充足」と読まない。
- **駆血が長い／溶血検体**：K・LD・AST・間接ビリルビンが上昇。**単独の K 高値・LD 高値は再検を促す**。

## 3. 生理的状態

### 急性の炎症・感染（採血前 1〜2週）
CRP が上がっていたら、次の解釈を**すべて保留**する。
- **フェリチン ↑（偽高）** — 鉄充足と読まない。CRP と必ずセットで見る（既存ルール）
- **血清鉄 ↓ / TSAT ↓** — 鉄欠乏と断定しない
- **亜鉛 ↓** — **急性期に低下する。栄養欠乏と断定せず、炎症が落ち着いてから再評価**
- **Alb ↓** — 低栄養と断定しない（負の急性期蛋白）
- **コレステロール ↓**

### 月経・直近の出血 ［lifestage.md と連動］
- 経血量が多い、または直近の出血があれば、Hb・フェリチンは低く出やすい。
- 逆に**閉経後で高フェリチン**なら、鉄過剰側と炎症の両方を疑う（鉄を勧めない）。

### 妊娠
- 血漿量が増えるため **Alb・Hb は希釈で低下**。**ALP は胎盤由来で上昇**。フェリチンは低下。
- → 妊娠中の値は一般の理想値で判定しない。用量を伴う提案は行わない（`lifestage.md`）。

### 加齢・筋肉量
- **クレアチニンは筋肉量に依存**する。筋肉が少ない高齢者・小柄な方は、クレアチニンが低く出て
  **eGFR が実際より良く見える**。腎機能ガード（eGFR 60未満でたんぱく質増量停止）を適用する際は、
  この方向の誤差があることを踏まえ、境界域では慎重側に倒す。

### 季節
- **25-OHビタミンD** は冬春に低く夏に高い。採血月を必ず確認する（`vitamin-d-evidence.md`）。

## 4. 薬・サプリによる測定干渉 ［問診 16・18］

`interactions.md` は「提案 × 薬」の安全面を扱う。ここで見るのは**測定値そのものへの干渉**。

| 要因 | 影響 |
|---|---|
| **高用量ビオチン（B7）** | 免疫測定法に干渉し、**TSH・FT4・FT3 が偽の値**になりうる（甲状腺の判定を誤らせる）。サプリ歴があり甲状腺の値が不自然なら、休止後の再検を医師経由で提案する |
| 鉄剤 | 血清鉄が服用直後に大きく上昇。フェリチンとあわせて見る |
| **ビタミンD サプリ** | 25-OHD 60 ng/mL 超では摂取歴を必ず確認（既存ルール） |
| ビタミンB12 サプリ | 血中B12は高く出るが、細胞内で使えているかは別。MCV・MMA と併せる |
| 経口避妊薬・ホルモン補充 | TG↑、**銅↑**（セルロプラスミン増加）。銅高値を過剰摂取と読まない |
| ステロイド | 血糖↑、WBC↑ |
| 胃酸抑制薬（PPI・H2ブロッカー） | PGⅠ低値・B12/鉄/亜鉛の吸収低下を**薬剤性**として解釈（既存ルール） |
| スタチン | CK↑ |

## 5. 測定機関・測定法の違い

経時比較で最も見落とされる交絡。基準値・単位・測定法が変われば単純比較できない
（`longitudinal-comparison.md`）。**施設が変わっている場合は、差分表に注記を入れる。**

## レポートへの書き方

交絡を検出したら、所見を消すのではなく**保留として明示する**。

> 例：「MCVが 98 fL とやや大きめですが、週に数回の飲酒があるため、
> ビタミンB12・葉酸の不足だけでなく、アルコールの影響も考えられます。
> 判断を分けるために、次回は採血前の1〜2週間を控えめにしたうえで確認できると確実です。」

- 断定の強さを下げるだけで、**提案を止める必要はない**（食事からのB群は交絡があっても妥当）
- 「次回はこの条件をそろえて測りましょう」は、継続の動機づけにもなる

【根拠】飲酒・喫煙・急性期反応・採血条件による各マーカーの変動＝〔確立〕／
ビオチン干渉＝〔確立〕／個々の閾値や戻るまでの期間＝〔目安〕
