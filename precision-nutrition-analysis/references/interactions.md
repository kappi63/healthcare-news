# 相互作用チェック（サプリ・薬・栄養素）

提案する栄養素・食品が、クライアントの**服薬（問診[16]）・既に摂っているサプリ（問診[18]）**と
ぶつからないかを確認する。商品として提供する以上、安全性の最終ゲートにあたる。

## 実施タイミング（Step 3の最後・必須）
改善提案を確定する**前**に、次の3方向を必ず確認する。
1. **提案 × 服薬**: これから勧める栄養素が薬の効果を妨げないか／薬が栄養素の吸収を妨げていないか。
2. **提案 × 既存サプリ**: 重複・過剰にならないか、バランスを崩さないか。
3. **服薬 × 血液所見**: 薬剤性の交絡で数値が動いていないか（＝所見の解釈に影響）。

## 原則
- ここでの目的は**「提案を安全側に調整する」**こと。薬の変更・中止は**絶対に提案しない**（医師の領域）。
- 該当したら、提案を修正するか、**「主治医・薬剤師にご相談ください」を明記**する。
- 相互作用の可能性を過度に不安にさせない。「時間をずらす」等の実践的な回避策を添える。
- 表にない薬・サプリでも、**服薬中と分かっている場合は「主治医・薬剤師に確認」を基本姿勢**にする。
- 【根拠】下記の主要項目は〔確立〕。個別の程度・臨床的意義には幅がある。

## A. 栄養素どうしのバランス（提案時に最も起きやすい）
| 組み合わせ | 内容 | 対応 |
|---|---|---|
| **亜鉛 × 銅** | 亜鉛の長期・高用量補充で銅が低下しうる | 亜鉛を勧める際は銅の値も確認。長期なら銅とのバランスを見て、必要なら医師相談 |
| **鉄 × 亜鉛／カルシウム** | 同時摂取で互いに吸収を妨げる | 摂取タイミングをずらす |
| **カルシウム × 鉄・亜鉛・マグネシウム** | 吸収競合 | 食事とサプリの時間を分ける |
| **ビタミンD × カルシウム** | 併用で尿路結石リスク増の報告（WHI） | **結石既往者は特に注意**。Ca併用は控えめに、医師相談（`vitamin-d-evidence.md` 参照） |
| **葉酸 × ビタミンB12** | 葉酸単独の高用量はB12欠乏の血液所見（大球性）を隠しうる | B群はセットで評価。MCV高値時はB12も併せて確認 |
| **ビタミンA（レチノール）過剰** | 過剰は有害。妊娠中は特に注意 | 高用量サプリは避ける（BCO1の型でも既成型を"適度に"） |

## B. 薬 × 栄養素（提案の調整が必要）
| 薬 | 影響 | 対応 |
|---|---|---|
| **胃酸抑制薬（PPI・H2ブロッカー）** | 胃酸低下により**B12・鉄・亜鉛・マグネシウム**の吸収が低下 | 低胃酸パターン(A1)は**薬剤性**として解釈。消化サポート（酸味・ベタインHCl等）は**必ず医師相談**。栄養は食事中心で提案 |
| **ワルファリン（抗凝固薬）** | **ビタミンK**で効果が変動。納豆・クロレラ・青汁・大量の緑葉野菜 | **納豆等を勧めない**。緑葉野菜は「量を一定に保つ」。必ず主治医へ |
| **メトホルミン** | 長期で**B12**が低下しうる | MCV・B12に注意。B12の確認を勧める（薬は変えない） |
| **スタチン** | 筋症状・**CK上昇**。CoQ10低下の議論 | CK高値は薬剤性も考慮。筋症状があれば医師へ |
| **利尿薬（ループ／サイアザイド）** | K・Mg・Naの変動（サイアザイドはCa上昇） | 電解質の解釈に注意。Mg/Kの自己判断サプリは避け医師へ |
| **甲状腺ホルモン薬** | 鉄・カルシウム・大豆・食物繊維で吸収低下 | 服用と**4時間程度あける**。医師の指示を優先 |
| **抗菌薬（テトラサイクリン系・キノロン系）** | **Ca・Mg・鉄・亜鉛**と結合し双方の吸収低下 | 服用時間をずらす（服薬期間中） |
| **ステロイド** | Ca・骨代謝・血糖に影響 | 骨とビタミンD・Caの評価は医師と |
| **NSAIDs（ロキソプロフェン等）** | 胃粘膜・鉄（消化管出血） | 常用なら鉄・胃症状に注意し医師へ |
| **経口避妊薬** | B6・葉酸・亜鉛の需要増、フェリチン上昇の報告 | B群の評価に注意 |

## C. サプリ × 薬（既に摂っているものの確認）
| サプリ | 注意 | 対応 |
|---|---|---|
| **セント・ジョーンズ・ワート** | 多くの薬の効果を低下（CYP誘導） | 服薬中は医師・薬剤師へ必ず確認 |
| **高用量ビタミンE・EPA/DHA・ニンニク** | 抗凝固薬との併用で出血傾向 | 服薬中は医師へ |
| **高用量ビタミンC** | 一部検査値・鉄吸収に影響 | 極端な高用量は避ける |
| **鉄剤** | PPI・制酸剤・お茶・カルシウムで吸収低下 | 空腹時＋ビタミンC、時間をずらす |
| **カフェイン（サプリ含む）** | CYP1A2遅い代謝型では負担 | 遺伝子モジュールと連動 |

## D. 妊娠・授乳・小児（該当時は特に慎重に）
- 妊娠可能年齢では**葉酸**の優先度が上がる。**ビタミンA高用量は避ける**。
- 妊娠中・授乳中・小児への用量提案は行わず、**医師・管理栄養士の指導を優先**する旨を明記。

---

## レポートへの反映
- 該当があれば、改善プランの中に**自然な形で**織り込む（別枠で不安を煽らない）。
  例:「鉄を含む食品は、お茶やカルシウムと時間をずらすと吸収が高まります」
- 医師相談が必要なものは、その提案のすぐそばに一文添える。
  例:「〇〇を服用中とのことですので、サプリメントの導入可否は主治医にご確認ください」
- **薬の変更・中止は書かない**。
- 服薬・サプリの情報が問診票に無い場合は、提案の一般的な注意に留め、必要なら確認を促す。
